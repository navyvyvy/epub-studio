    TXT에서 EPUB으로 변환

    파일을 개별·일괄 변환할 수 있습니다. 새 파일만 분석해 기존 결과를 유지합니다. 목록·미리보기·검색·EPUB은 회차를 뺀 제목을 함께 사용하며, 원본 TXT는 유지합니다. 진행률은 변환 버튼 안에 표시하며, 같은 버튼으로 중단을 요청할 수 있습니다.

    공백 정제

    불필요한 연속 빈 줄은 줄이고, 문단 사이의 여백은 너무 과하게 건드리지 않습니다.

    목차 추출

    파일 전체에서 유효한 제목이 가장 많은 형식을 고릅니다. 회차·괄호 번호의 흐름을 확인하고, 시각·날짜 범위는 제외합니다.

    목차 미리보기

    파일별로 제목 패턴을 바꾸거나, 회차 추가 감지로 본문에 붙어 놓친 제목을 찾을 수 있습니다. 애매한 줄은 추가 회차 후보에서 확인하고, 필요 없는 제목은 목차에서 제외할 수 있습니다.

    표지 적용과 작품 정보

    이미지를 검색하거나 클립보드에서 표지를 붙일 수 있습니다. GitHub Pages와 Vercel에서 작품 정보를 조회하며, 상태 배지·평점·평가 인원수를 표시합니다. 조회 중에는 중복 검색을 막고, 결과가 바뀌어도 창 높이를 유지합니다. 실패한 사이트만 다시 조회할 수 있습니다.

    인코딩 자동 감지

    UTF-8, CP949 같은 흔한 인코딩을 자동으로 읽어들여 깨짐을 줄입니다.

    선택한 파일 합치기

    선택한 TXT만 목록 순서대로 EPUB 하나에 넣습니다. 파일별 목차 설정은 그대로 적용하고, ZIP을 선택하면 묶음과 나머지 EPUB을 함께 받을 수 있습니다.

    작동 방식

    파일은 브라우저 안에서 움직입니다

    TXT를 읽고 목차를 찾고 EPUB을 만드는 기본 흐름은 서버 업로드 없이 현재 브라우저에서 처리합니다.

    TXT

    파일을 직접 읽습니다

    UTF-8, CP949, UTF-16 계열을 확인해 원문이 깨지지 않도록 읽습니다.

    TOC

    제목 흐름을 분석합니다

    이어지는 번호와 반복되는 형식을 비교해 목차 후보를 만들고 미리보기에서 바로 다듬습니다.

    EPUB

    읽기 좋은 단위로 묶습니다

    긴 본문은 안전한 크기로 나누고 표지와 목차를 포함한 EPUB 파일로 내려받습니다.

    개인정보처리방침

    파일과 데이터 처리 방식을 안내합니다

    기본 변환은 사용자의 브라우저에서 진행되며 원문 파일을 서버에 저장하지 않습니다.

    1. 수집하는 정보

    회원가입이나 사용자 계정을 만들지 않습니다. 파일명, 제목, 정규식, 클립보드 이미지와 이미지 URL은 기본 변환에 필요한 범위에서 브라우저 안에서 사용합니다.

    2. 파일 처리 방식

    TXT 내용은 브라우저가 직접 읽고 Web Worker에서 변환합니다. 기본 동작은 로컬 처리이며 서버 업로드를 사용하지 않습니다.

    3. 외부 서비스

    CDN, 표지 검색, 클립보드, 광고 기능은 외부 요청을 보낼 수 있습니다. 작품 정보 조회 시에는 검색어만 조회 서버와 검색 대상 사이트에 전달하며, TXT 본문은 보내지 않습니다.

    4. 보관 및 삭제

    원문 파일을 서버에 저장하거나 브라우저 밖에 장기 보관하지 않습니다. 새로고침하거나 페이지를 닫으면 작업 상태가 초기화될 수 있습니다.
