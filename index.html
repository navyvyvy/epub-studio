TXT에서 EPUB으로 변환

여러 텍스트 파일을 한 번에 넣고 EPUB 파일로 변환합니다. 파일 단위로 상태를 확인할 수 있어 작업 흐름이 단순합니다.

공백 정제

무의미한 연속 빈 줄은 줄이고, 문단과 장면 전환에 필요한 여백은 살려 가독성을 유지합니다.

목차 추출

화, 회, Chapter, Episode 같은 표기를 감지해 목차로 묶습니다. 다중 패턴과 커스텀 정규식도 지원합니다.

목차 미리보기

파일별 목차 후보를 바로 확인하고, 각 줄은 눌러 복사할 수 있습니다. 감지 상태는 색으로 구분됩니다.

표지 설정

도서명을 검색하거나, 클립보드 이미지와 이미지 URL을 표지로 적용할 수 있습니다.

인코딩 자동 감지

UTF-8, CP949 같은 흔한 인코딩을 자동으로 판별해 깨짐을 줄입니다.

ZIP 일괄 압축

여러 EPUB 결과물을 하나의 ZIP 파일로 묶어 내려받을 수 있습니다.
