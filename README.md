# EPUB Studio

EPUB Studio는 브라우저에서 `TXT` 파일을 `EPUB`으로 변환하는 단일 페이지 웹 도구입니다.
파일 처리는 가능한 한 로컬 브라우저 안에서 끝나도록 설계했고, 변환 전에 목차 후보를 미리 확인할 수 있게 만든 점이 핵심입니다.
최근에는 첫 화면 접근성, 미리보기 흐름, 반응형 레이아웃을 다시 다듬어 전체 사용 흐름을 정리했습니다.

## 한눈에 보기

- `TXT -> EPUB` 일괄 변환
- 파일 드래그 앤 드롭 또는 클릭 추가
- 인코딩 자동 감지
- 목차 후보 감지 및 미리보기
- 미리보기 결과 행 단위 복사
- 다중 패턴/단일 패턴 전환
- 커스텀 정규식 기반 보정
- 표지 이미지 적용
- 진행 상태 표시와 중단
- 결과 EPUB 및 ZIP 다운로드
- 모바일/데스크톱 반응형 UI

## 주요 기능

### 파일 관리

- 여러 `TXT` 파일을 한 번에 추가할 수 있습니다.
- 파일별 제목, 인코딩, 진행 상태를 개별 관리합니다.
- 처리 완료 후에도 상태를 확인하면서 재검토할 수 있습니다.

### 목차 감지

- `제1화`, `1화`, `Chapter 2`, `Episode 3` 같은 패턴을 감지합니다.
- 다중 패턴 허용 여부에 따라 결과를 다르게 보여줍니다.
- 사용자 정의 정규식을 넣어 특정 제목 스타일을 추가할 수 있습니다.
- 목차 후보는 미리보기로 확인하고, 행 단위로 복사할 수 있습니다.
- 감지 여부는 목록에서 바로 확인할 수 있도록 정리했습니다.

### 변환 품질

- 연속 빈 줄을 정리해 읽기 좋은 EPUB을 만듭니다.
- 본문 오탐을 줄이기 위해 제목 후보를 단계적으로 걸러냅니다.
- 진행 중에는 상태와 진행률을 즉시 보여줍니다.

### 표지와 부가 기능

- Google 이미지 검색으로 표지를 찾을 수 있습니다.
- 클립보드 이미지를 표지로 적용할 수 있습니다.
- 결과물은 개별 EPUB 또는 ZIP 묶음으로 받을 수 있습니다.

## 페이지 구성

- [`index.html`](./index.html): 메인 변환 도구
- [`about.html`](./about.html): 사이트 소개
- [`privacy.html`](./privacy.html): 개인정보처리방침
- [`contact.html`](./contact.html): 문의 안내

## 동작 방식

- 변환과 파싱은 Web Worker에서 처리합니다.
- 파일 내용은 브라우저에서 직접 읽습니다.
- 외부 라이브러리는 CDN을 통해 불러옵니다.
- 앱은 정적 호스팅 환경에서도 동작하도록 구성되어 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. TXT 파일을 드래그 앤 드롭하거나 클릭해서 추가합니다.
3. 필요하면 공백 정제, 목차 추출, 다중 패턴, 커스텀 정규식을 조정합니다.
4. 표지가 필요하면 검색 또는 클립보드 기능을 사용합니다.
5. `EPUB 변환 시작`을 눌러 결과를 생성합니다.

## 브라우저 참고

- 데스크톱과 모바일 모두를 고려해 UI를 구성했습니다.
- 작은 화면에서는 표가 길어질 수 있어, 주요 조작은 상단과 첫 화면에서 바로 접근할 수 있게 배치했습니다.
- 최신 브라우저 기준으로 사용하는 것이 가장 안정적입니다.

## 개인정보 및 외부 요청

- 기본 변환은 로컬 브라우저에서 처리됩니다.
- 사용자가 직접 누른 기능에 따라 클립보드 접근이나 이미지 검색이 발생할 수 있습니다.
- CDN 로드가 포함되어 있으므로, 공개 배포 시에는 사이트 안내와 정책 페이지를 함께 운영하는 것이 좋습니다.
