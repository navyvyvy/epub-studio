# 📚 EPUB STUDIO

텍스트 파일을 정규식 기반으로 분석하여 전문가 수준의 EPUB 전자책으로 변환해주는 웹 도구입니다.

## 🚀 주요 업데이트 사항 (2026.05)

### 1. 지능형 목차 추출 엔진 (Smart TOC)
단순히 숫자를 찾는 것을 넘어, 문맥을 분석하여 본문과 제목을 구분합니다.
- **조사 판별**: `1화의`, `1화는` 등 제목 뒤에 조사가 붙는 문장은 본문으로 간주하여 제외합니다.
- **유연한 패턴**: `01. 프롤로그`, `#1 시작`, `【제 1화】` 등 다양한 웹소설 연재 포맷을 완벽하게 지원합니다.
- **문장 방어**: 마침표(.)나 느낌표(!)로 끝나는 일반 서술형 문장이 제목으로 오인되지 않도록 문장 끝 처리를 검증합니다.

### 2. 고해상도 뷰어 호환성 (XML Integrity)
일부 뷰어(리디북스, 킨들, 구글북스 등)에서 파일이 깨지거나 새로고침되는 현상을 원천 차단했습니다.
- **XML Safe Encoding**: 제목과 본문에 포함된 모든 특수문자를 XML 표준 규격으로 자동 이스케이프합니다.
- **Hybrid TOC**: 최신 규격인 `nav.xhtml`과 구형 기기를 위한 `toc.ncx`를 동시에 생성하여 모든 기기에서 목차를 사용할 수 있습니다.

## 🛠️ 정규식 가이드
현재 적용된 **통합 패턴**은 다음과 같은 구조를 가집니다:
- `제?\s*\d+화(?![이가을를은는의])`: '화' 뒤에 조사가 없는 경우만 제목으로 인식
- `(?!\d+(년|월|일)\b)`: 날짜 및 단위 정보 제외
- `.{1,30}(?<![\.\?\!])`: 문장 부호로 끝나는 긴 문장 제외

## ✨ 주요 기능

- **광범위한 기기 호환성 (EPUB 2 & 3)**:
  - 최신 표준인 **EPUB 3(nav.xhtml)**와 구형 e-잉크 단말용 **EPUB 2(toc.ncx)**를 동시 생성하여 리디북스, 킨들, 아이패드 등 모든 기기에서 완벽한 목차를 보장합니다.
- **인터랙티브 드래그 앤 드롭**:
  - 파일을 끌어다 놓기만 하면 즉시 목록에 추가되며, 드래그 시 시각적 피드백을 통해 직관적인 작업이 가능합니다.
- **지능형 목차 추출 엔진**:
  - 복잡한 통합 정규식을 통해 꺽쇠(`<>`), 화괄호(`【】`), 제~화, Chapter 등 다양한 포맷을 자동으로 감지합니다.
- **배치 프로세싱 & 고성능**:
  - 수십 개의 파일을 한 번에 변환하고 ZIP으로 압축 다운로드하며, 모든 처리는 로컬(Zero-Server)에서 이루어져 안전합니다.
- **스튜디오 테마 UI**:
  - 장시간 작업에도 눈이 편안한 다크 모드 기반의 전문적인 작업 환경을 제공합니다.

## ⚙️ 목차 인식 정규식 가이드 (최신화)

실제 사용 중인 통합 패턴에 맞춰 최적화된 가이드를 제공합니다.

| 패턴 이름 | 설명 및 인식 대상 |
| :--- | :--- |
| **통합 패턴** | 괄호(`【】`, `< >`), 제~화, Chapter, #숫자 등을 모두 포함하는 강력한 패턴 |
| **특수 괄호** | `【001】`, `<공지>`, `〔제1화〕` 등 특수 기호로 감싸진 제목 |
| **플랫폼 표준** | `제 10화. 본문 시작` (카카오페이지, 문피아 등 주요 플랫폼 형식) |
| **영문/넘버링** | `Chapter 1`, `#123`, `(1)` 등 영문 및 단순 숫자 넘버링 |
| **일반 제목** | `1. 새로운 시작` 등 숫자로 시작하며 특정 종결어미가 없는 문장 |
| **통합 패턴 (권장)** | **001화**, **#002**, **제 1화** 등을 지원하며, 본문 내 서사(예: 1화의 조회수...)는 조사를 판별하여 자동으로 제외합니다. |

## 🚀 시작하기

1. 변환할 텍스트 파일을 중앙의 **Drop Zone**으로 드래그합니다.
2. 우측의 **정규식 가이드**에서 본문에 맞는 샘플을 클릭하거나 직접 패턴을 입력합니다.
3. 변환 버튼을 눌러 생성된 EPUB 또는 ZIP 파일을 다운로드합니다.
