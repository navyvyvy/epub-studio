# EPUB Studio

EPUB Studio는 브라우저에서 `TXT` 파일을 `EPUB`으로 바꾸는 웹 도구입니다.
파일은 가능한 한 로컬 브라우저 안에서 처리하고, 변환 전에 목차 후보도 바로 확인할 수 있게 만든 점이 핵심입니다.
최근에는 첫 화면 진입, 미리보기 흐름, 반응형 레이아웃을 다시 손봐서 전체 사용 흐름을 다듬었습니다.

## 한눈에 보기

- `TXT -> EPUB` 일괄 변환과 파일별 단독 변환
- 드래그 앤 드롭이나 목록의 빈 공간 클릭으로 파일 추가
- 인코딩 자동 감지
- 목차 자동 감지와 미리보기
- 파일 전체의 유효 제목 수를 비교해 가장 많은 형식을 주 목차로 선택
- 미리보기 결과를 행 단위로 복사
- 파일별 단일 패턴과 다중 패턴 전환
- 커스텀 정규식으로 보정
- 표지 이미지 적용
- 진행 상태 표시와 중단
- 결과 EPUB과 ZIP 다운로드
- 모바일과 데스크톱 모두 대응하는 UI

## 주요 기능

### 파일 관리

- 여러 `TXT` 파일을 한 번에 추가할 수 있습니다.
- 파일을 더 넣으면 새 파일만 분석합니다. 기존 파일의 감지 결과와 파일별 설정, 제목 제외 상태는 유지합니다.
- 목록에 파일이 있어도 빈 공간 어디든 클릭하거나 드래그해 더 넣을 수 있습니다. 같은 추가 안내를 빈 목록에서는 중앙에, 파일이 있으면 하단에 표시합니다. 파일 추가 영역에 키보드 초점을 두고 Enter 또는 Space를 눌러도 추가할 수 있습니다.
- 파일별 제목, 인코딩, 진행 상태를 따로 관리합니다.
- 목록의 `변환` 버튼으로 필요한 파일 하나만 바로 EPUB으로 만들 수 있습니다.
- `목록 초기화`는 추가한 파일과 목차 선택을 비웁니다. 원본 파일과 공통 설정은 건드리지 않으며, 변환 중에는 누를 수 없습니다.
- 처리 후에도 상태를 보면서 다시 확인할 수 있습니다.

### 목차 감지

- `제1화`, `1화`, `Chapter 2`, `Episode 3` 같은 패턴을 감지합니다.
- 같은 제목의 회차와 괄호 번호를 함께 비교해 일부 회차 순서가 뒤바뀌어도 목차를 복구합니다. 본문 순서는 원문을 유지하며, 회차 제목은 다른 형식 후보에 섞지 않습니다.
- 단일 패턴은 파일 전체에서 유효한 제목이 가장 많은 형식을 고릅니다. 다중 패턴은 검사를 통과한 여러 형식을 함께 보여줍니다.
- 목록의 `다중` 버튼이나 미리보기의 `다중 패턴`으로 해당 파일만 바꿀 수 있습니다. 다른 파일의 설정은 유지되며, EPUB과 ZIP에도 파일별 설정을 적용합니다.
- 위쪽 `여러 형식 감지`는 새로 추가할 파일과 파서 시뮬레이터에만 적용합니다. 파일별 설정은 목록에서 지우거나 페이지를 나갈 때까지 유지하며, 완료한 파일의 설정을 바꾸면 그 파일만 다시 변환할 수 있는 대기 상태가 됩니다.
- 사용자 정의 정규식을 넣어 원하는 제목 스타일을 보정할 수 있습니다.
- 목차 후보는 미리보기에서 확인하고, 행 단위로 복사할 수 있습니다.
- 괄호 번호가 붙은 다른 형식도 기본 감지 결과와 개수를 비교합니다. 중복과 본문을 제외한 후보가 같은 형식에서 2개 이상 확인돼야 제안하며, 자동 선택되지 않은 후보는 미리보기에서 직접 추가할 수 있습니다.
- 자동 감지에 없는 형식도 같은 표식의 번호가 증가하며 반복되면 제목으로 인식합니다.
- 제목 수가 같으면 파일명의 `1-200` 같은 범위를 참고하고, 그래도 같으면 파일에서 먼저 나온 형식을 고릅니다. 본문 오탐과 중복을 뺀 뒤 개수를 셉니다.
- 감지 결과는 목록에서 바로 볼 수 있게 해 두었습니다.

### 변환 품질

- 연속 빈 줄을 정리해 읽기 좋은 EPUB을 만듭니다.
- 본문 오탐을 줄이도록 제목 후보를 단계적으로 걸러내며, 시각·타임코드와 날짜 범위는 목차에 넣지 않습니다.
- 진행 중에는 상태와 진행률을 바로 보여줍니다.

### 표지와 부가 기능

- Google 이미지 검색으로 표지를 찾을 수 있습니다.
- 클립보드 이미지를 표지로 적용할 수 있습니다.
- 결과물은 EPUB 한 개씩 또는 ZIP 묶음으로 받을 수 있습니다.

## 동작 방식

- 변환과 파싱은 Web Worker에서 처리합니다.
- 파일 내용은 브라우저가 직접 읽습니다.
- 외부 라이브러리는 CDN으로 불러옵니다.
- 정적 호스팅 환경에서도 돌아가도록 만들었습니다.
- 제목 정규식과 파싱 우선순위는 [`PARSER_GUIDE.md`](./PARSER_GUIDE.md)에 정리되어 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. TXT 파일을 드래그 앤 드롭하거나 클릭해서 넣습니다.
3. 필요하면 공백 정리, 목차 추출, 다중 패턴, 커스텀 정규식을 조정합니다.
4. 표지가 필요하면 검색이나 클립보드 기능을 씁니다.
5. 한 파일만 만들 때는 해당 행의 `변환`, 전체를 처리할 때는 `EPUB 변환 시작`을 누릅니다.

## 브라우저 참고

- 데스크톱과 모바일을 함께 고려해 UI를 구성했습니다.
- 상단 메뉴는 현재 화면에서 가장 많이 보이는 영역을 표시합니다. 메뉴 클릭과 스크롤 이동, 한영 전환 때도 표시를 갱신합니다.
- 언어 전환에는 글꼴에 영향을 받지 않는 SVG 국기를 사용합니다. 하단에는 개인정보처리방침, 문의, 변환 도구로 돌아가기만 남겨 긴 페이지에서도 바로 이동할 수 있게 했습니다.
- 데스크톱에서는 왼쪽에 설정과 상태, 오른쪽에 파일 목록을 표시합니다. 추가 안내는 목록 안쪽 하단에 두고, 목록 바로 아래에는 초기화와 변환 버튼을 나란히 둡니다. 상태창의 문구는 가운데 정렬하며, 모바일에서는 설정, 목록, 변환 버튼, 상태 순서로 표시합니다.
- 파일이 많으면 목록 안에서 스크롤합니다. `목차 감지 도구`는 별도 창에서 열어 정규식과 파서 시뮬레이터를 넓게 사용할 수 있으며, 뒤의 파일 목록 크기는 바뀌지 않습니다.
- 최신 브라우저에서 쓰는 편이 가장 안정적입니다.

## 개인정보 및 외부 요청

- 기본 변환은 로컬 브라우저에서 처리됩니다.
- 사용자가 직접 누른 기능에 따라 클립보드 접근이나 이미지 검색이 열릴 수 있습니다.
- CDN 로드가 들어가 있으니, 공개 배포할 때는 안내 페이지와 정책 페이지를 함께 두는 편이 좋습니다.

## 참고

- 처음 들어왔을 때 바로 변환 흐름이 보이도록 구성했습니다.
- 파일 목록, 목차 미리보기, 상태 표시는 나눠서 관리하기 쉽게 두었습니다.
- 버튼의 모양과 크기는 `ui-buttons.css`에서 함께 관리합니다. 기본 버튼은 `ui-button`, 목록용은 `ui-button--compact`, 큰 작업 버튼은 `ui-button--large`를 추가합니다. 각 기능의 CSS에는 배치와 감지·처리 상태만 둡니다.
